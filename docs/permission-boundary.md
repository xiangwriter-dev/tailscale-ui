# 当前功能与权限边界

更新：2026-09-24。软件显示名 **xiangwriter远程器**，公开仓库 **xiangwriter-dev/tailscale-ui**。

用户已明确撤回“Agent 只有修复，没有操控权”的限制，恢复原始需求中的远程命令、脚本和任务管理。0.2.0 实现配对执行端、命令/脚本、输出与进度、取消/超时、结果文件下载。本机数据库修复保留为独立功能，不会把所选设备误当作本机修复目标。

## 用户操作与授权

- 安装或打开控制窗口不会自动开启执行端。用户在目标设备选择工作目录并开启服务，生成五分钟有效的单次配对信息。
- 控制端核对节点与证书指纹后完成配对；任务必须由用户选择目标并提交。
- Agent 以目标当前账户权限运行。工作目录检查不构成命令沙箱，也不限制被授权脚本能访问的所有系统资源。
- 关闭控制窗口不会停止已开启的后台执行端。停止执行端可以排空已接受任务或取消后停止；登录自启默认关闭。
- 撤销授权后，该控制端不能再提交、读取或取消任务。此前已接受任务继续运行，可由目标机器本地停止服务来取消。

## 实现边界

服务只绑定经当前官方 Tailscale 状态确认的本机地址；TLS 固定证书并验证地址，禁止继承代理和跟随重定向。服务端保存令牌摘要，控制端令牌及服务私钥使用系统凭证库，不提供明文降级。控制端和执行端 SQLite 使用独立目录、独占锁、迁移前备份。

同一控制端的相同请求 ID 与内容只接受一次；不同内容冲突会拒绝。断网保留最后观测，启动恢复把已开始但结果不明的任务标记为待核实，不自动重跑。结果收集失败不覆盖命令退出状态。

当前不包含屏幕画面、鼠标键盘控制、交互式终端、Tailscale 网络配置修改、自动更新、代码签名或 Apple 公证。跨平台构建和实机验收分别记录，详见 [验证记录](validation.md)。

0.1.0 的“仅修复”限制只属于历史基础版本，不再作为当前产品约束。历史提案保留用于追溯；继续开发以 CONTEXT.md 和 remote-task-execution 规格为准。
