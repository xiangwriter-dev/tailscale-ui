# 权限边界与本次范围

软件名称由用户于 2026-09-24 指定为 **xiangwriter远程器**；GitHub 仓库为公开的 xiangwriter-dev/tailscale-ui，内部代码代号仍为 TailTask。

用户在原 PRD 之后明确“agent 只有修复，没有操控的权利”。关于 Agent 指代的澄清没有获得更细定义，因此当前采用保守边界：只实现编译时定义的本机应用自检与修复动作。原 PRD 的任意远程命令、脚本、终端、进程控制和设备操控条目不适用于本基础版。

用户随后选定简约风格、少量科技元素，并要求 GPT Image 生图。该设计选择已实现；历史“UI 待选择”的文案已废止。

允许动作是本产品数据库完整性检查及派生索引重建。用户主动发起后，只作用于这台电脑的本产品数据库。设备选择只用于查看状态及编辑本地偏好，不会更换修复目标。

后端使用严格枚举解析动作；JSON 中出现 command、script、executable 等未知字段会被拒绝。没有监听远程请求的 Agent 服务，没有通用 shell、脚本上传、Tailscale 登录/路由/DNS 修改入口。

任务先持久接受再执行。终态和事件原子保存；无法保存时显示“状态待核实”，不伪报成功。启动恢复会把遗留任务标为中断，禁止自动重放。

未来远程修复仍需另行定义：允许的动作、目标机器权限、身份认证、配对与撤销。未明确这些范围前保持关闭。三平台的“能构建”和“已在对应系统安装使用”分别记录，不能互相替代。
