# 远程任务使用与实现边界

显示名：xiangwriter远程器。0.2.0 为无签名测试版。

## 连接与运行

1. 两端安装官方 Tailscale 并加入预期网络，网络策略需允许目标的 TCP 47321。
2. 在目标机器打开“本机执行端”，选择本机允许工作目录后开启。服务使用当前用户，不要求管理员；默认不开启。
3. 在目标生成配对信息，完整复制到控制端的“远程任务 → 配对设备”，核对设备和证书指纹。配对有效五分钟、一次消费，连续五次错误使其失效。
4. 选择已配对设备，输入目标的绝对工作目录、程序及参数数组，或选择目标已安装的脚本解释器。点击“在目标设备运行”提交。
5. 日志、取消、任务状态和结果下载位于任务详情。断线显示最后观测；提交结果未知时重试同一请求，不自动换号执行。

Windows PowerShell 的脚本模式默认遵循系统执行策略。如本机默认 Restricted，可在任务表单显式选择“仅本次进程使用 RemoteSigned”；仅该脚本进程及子进程生效，不写入系统或用户全局策略，组策略仍有优先权。PowerShell 脚本输出设为 UTF-8；exec 模式的其他程序应自行使用 UTF-8 输出。

## 数据与授权

控制端使用 controller.db，执行端使用独立 agent/agent.db。数据库升级至模式 4 前生成一致性备份，原有迁移保持不变。模式 4 保存已同步的结果文件清单，离线或重开后仍可查看；下载文件本身仍需远端在线。旧版 0.1.0 不能打开升级后的数据库。

控制端令牌、服务私钥和本机管理凭据使用系统凭证库；SQLite 只存令牌摘要或引用。Linux 需要登录会话的 Secret Service；凭证库不可用时明确失败，不降级明文。证书及公开节点信息不属于凭据，可保存在本地连接记录。重新配对不能恢复已撤销身份的任务访问权。

目录限制用于核对 cwd 和收集结果，不是命令沙箱。已配对的控制端可以使用执行账户权限运行命令。撤销授权后不能提交、读取或取消该授权的任务，已接受任务默认继续。

## 生命周期与结果

关闭控制窗口不会结束执行端。排空停止先关闭接单、等已接受任务完成；中止停止按取消规则处理。Windows 使用 Job Object 和受控 worker 启动屏障；POSIX 使用进程组。取消有五秒宽限，无法确认退出或结果写入失败时不能宣称成功。异常重启后已启动任务进入待核实，不自动重放。

默认并发 1，最大 4，等待队列最多 100。日志保留最多 16 MiB，超限继续排空进程输出。仅自报的 TAILTASK_PROGRESS JSON 显示百分比。详情显示最近 2000 条已载入事件，本地库保存已同步记录。

结果目录只能是 cwd 内相对子目录；拒绝 symlink/reparse point 和特殊文件，每次最多 100 文件、单文件 500 MiB、总计 1 GiB。收集失败不篡改进程退出状态。下载先写 .partial，支持从已有长度继续，SHA-256 验证后以不覆盖已有文件的方式完成保存。

平台登录启动功能需用户在本机开启：Windows 当前用户登录任务、macOS LaunchAgent、Linux systemd 用户服务。实际注册失败会显示错误，不显示虚假成功。

## 验证限制

仅 Windows 主机具备真实 Tailscale、系统凭证库和安装验证环境。macOS/Linux 的 CI 检查不能替代各系统上的原生窗口、凭证授权提示、登录启动与跨设备 3×3 实测。见 validation.md。
