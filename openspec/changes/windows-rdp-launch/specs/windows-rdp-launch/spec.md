# Spec Delta

## Purpose

让已配置 Windows 远程桌面的用户直接从应用发现的 Tailscale 设备发起连接，复用 Windows 的登录和会话界面，并将远程桌面与本应用的命令执行端配对清楚区分，减少重复配置和误导。

## ADDED Requirements

### Requirement: 直接发起系统远程桌面连接
Windows 客户端 SHALL 为当前网络可见的远程 Windows 设备提供列表和详情连接入口，不要求远程任务执行端配对，不采集或存储 Windows 密码。

#### Scenario: 已配置的目标
- **WHEN** 用户点击可见远程 Windows 设备的远程桌面按钮
- **THEN** 系统使用重新读取的目标地址打开 Windows 远程桌面客户端，显示已打开客户端提示而不是已登录成功

#### Scenario: 本机和不可用平台
- **WHEN** 选择本机、非 Windows 目标，或本机不是 Windows
- **THEN** 入口给出不可用原因，不误启动连接

### Requirement: 启动前确认目标
系统 MUST 从最新 Tailscale 状态确认网络身份和节点，拒绝历史记录、已变更网络、不可见节点和无效地址；只允许固定远程桌面客户端的结构化目标参数，不接受任意程序、附加参数或凭据。

#### Scenario: 列表显示后网络切换
- **WHEN** 用户点击旧网络设备而最新网络身份已变化
- **THEN** 不打开客户端并提示刷新设备

#### Scenario: 程序启动失败
- **WHEN** 系统客户端不存在或进程无法启动
- **THEN** 界面显示具体失败原因并允许重试，不显示已打开

### Requirement: 网络读取与任务配对说明
系统 SHALL 在启动、手动刷新及返回可见窗口时读取设备，并保持现有定时刷新；远程任务配对界面明确说明其用途，并给出返回设备远程桌面入口。

#### Scenario: 从系统设置返回应用
- **WHEN** 用户回到前台窗口
- **THEN** 设备列表发起状态更新，重复刷新不并行堆积

#### Scenario: 误进入任务配对
- **WHEN** 用户打开任务配对弹窗
- **THEN** 能看到系统远程桌面无需任务配对的说明，并可返回设备页
