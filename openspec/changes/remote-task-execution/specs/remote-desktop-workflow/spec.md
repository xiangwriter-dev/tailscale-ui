# Spec Delta

## Purpose

在简约科技风的 xiangwriter远程器 桌面界面中连接设备选择、配对、创建任务与结果查看，使用户始终知道操作目标和执行账户，并在本地保存可恢复的远程任务历史。

## ADDED Requirements

### Requirement: 目标明确的任务表单
已配对且实时身份匹配的设备 SHALL 提供新建任务入口。表单展示目标设备、执行账户、工作目录、模式、命令或脚本及超时。运行按钮是明确的提交动作，列表选择本身不得执行命令。

#### Scenario: 改变网络或目标
- **WHEN** 表单打开后当前网络身份变化
- **THEN** 禁止原表单继续提交，保留草稿并要求重新核对目标

### Requirement: 本机执行端页面
桌面 SHALL 提供开启、状态、允许目录、并发、生成配对信息、授权列表与撤销入口。允许目录由目标机器本地选择，不把控制端文件选择器误当作远端目录选择器。

#### Scenario: 生成配对信息
- **WHEN** 已开启的目标执行端生成配对信息
- **THEN** 显示有效期、设备与证书信息，允许用户复制到控制端，不写入普通日志

### Requirement: 本地远程历史
控制端 SHALL 持久保存目标快照、请求 ID、提交状态、远端 ID、同步时间、事件与结果索引。重开后恢复查询，提交未知与执行失败分别显示。只显示真实数据，不注入概念图设备。

#### Scenario: 重开控制端
- **WHEN** 本地 UI 关闭后重新打开
- **THEN** 历史仍在，已接受远端任务继续按原 ID 查询，不重新执行

### Requirement: 平台安装与发布
Windows、macOS arm64/x64、Ubuntu 24.04 x64 SHALL 分别构建原生安装包并记录真实验收状态，Windows 使用 setup.exe。安装包含执行端能力，显示名为 xiangwriter远程器。未签名构建必须明确标注。

#### Scenario: 安装后首次启动
- **WHEN** 用户首次启动应用
- **THEN** 进入控制界面，执行端保持关闭，提示安装/登录官方 Tailscale 所需步骤
