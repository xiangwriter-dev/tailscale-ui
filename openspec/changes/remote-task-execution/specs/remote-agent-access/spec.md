# Spec Delta

## Purpose

让设备所有者显式开启 xiangwriter远程器 执行端，并通过可验证的目标身份和独立控制端授权连接设备，使远程执行权限与 Tailscale 网络可见性分别管理且可随时撤销。

## ADDED Requirements

### Requirement: 执行端必须由所有者开启
执行端 SHALL 默认关闭，以当前用户权限运行。开启时要求选择允许工作目录，展示执行账户、绑定地址及端口；关闭 UI 不得终止执行端。安装不得自动授权其他设备。

#### Scenario: 只安装应用
- **WHEN** 用户完成安装但尚未开启执行端
- **THEN** 不监听远程任务端口，设备不能接收远程执行请求

#### Scenario: UI 关闭
- **WHEN** 已开启执行端且控制窗口关闭
- **THEN** 已接受任务继续执行，重开窗口后可查看执行端状态

### Requirement: 身份和配对
网络服务 MUST 只绑定已观测的本机 Tailscale 地址，使用 TLS；控制端 MUST 校验配对信息中的证书与节点身份，禁止忽略证书验证或自动跟随重定向。配对信息有效期 5 分钟、单次消费，连续 5 次错误撤销会话；成功后发放独立控制端令牌。

#### Scenario: 网络可见但未配对
- **WHEN** 未授权设备连接任务 API
- **THEN** 拒绝执行和日志读取，不泄露其他任务

#### Scenario: 凭据复用或证书改变
- **WHEN** 配对凭据已使用、过期，或目标证书不匹配
- **THEN** 明确拒绝连接，不回退到不验证证书的模式

### Requirement: 凭证保护与撤销
控制端令牌 MUST 保存在平台凭证存储，业务 SQLite 只保存引用；远端只保存令牌摘要。普通控制端仅访问自己的任务。所有者可以撤销授权，旧令牌随即失效，已有任务默认继续。

#### Scenario: 控制端被撤销
- **WHEN** 所有者撤销某个控制端
- **THEN** 该控制端不能再提交、查看或取消任务；其他授权不受影响

### Requirement: 停止执行端
停止 SHALL 展示活动任务数量并支持排空后停止；明确中止模式按任务取消规则结束任务。启动或注册失败 MUST 显示原因，不显示虚假运行状态。

#### Scenario: 活动任务仍存在
- **WHEN** 用户选择排空后停止
- **THEN** 停止接受新任务，等待已接受任务结束再关闭服务
