# Spec Delta

## Purpose

为已配对的设备提供用户主动发起的远程命令和脚本任务，持续保存真实执行状态、输出、退出码和结果文件，并在断线、重试及进程故障时避免重复执行或误报成功。

## ADDED Requirements

### Requirement: 命令与脚本请求
任务 SHALL 包含名称、目标身份、绝对工作目录、执行模式、超时与请求 ID。exec 模式使用独立可执行文件和参数数组，script 模式使用目标上实际可用的解释器。工作目录必须在目标所有者配置的目录内；脚本最多 256 KiB，超时 1–86400 秒，环境变量最多 50 项/16 KiB。工作目录限制不得宣称为进程沙箱。

#### Scenario: 跨系统参数
- **WHEN** 参数含中文、空格或引号
- **THEN** 由目标进程按独立参数接收，控制端不执行该命令

#### Scenario: 非法目标或解释器
- **WHEN** 目录超出允许范围、身份已变化或解释器不存在
- **THEN** 拒绝任务并显示准确原因

### Requirement: 持久接受与去重
Agent MUST 在执行前持久保存任务、请求内容摘要和初始事件。相同控制端/请求 ID/内容只能创建并执行一次，异内容同号必须冲突。默认并发 1、可配置 1–4、最多等待 100 项。提交响应丢失时控制端 SHALL 保留原请求 ID，不能自动新建任务。

#### Scenario: 响应丢失
- **WHEN** 接受响应丢失后控制端重试
- **THEN** 返回原任务，执行次数保持一次

### Requirement: 日志与真实状态
Agent SHALL 持久保存带单调序号的 stdout、stderr 与事件，提供分页补齐；限制内存和单任务留存大小。UI 按文本展示、过滤终端控制符，不渲染输出 HTML。未报告进度的任务不得显示推测百分比；只有真实正常退出码 0 才能标记成功。

#### Scenario: 网络短暂断开
- **WHEN** 正在运行的任务失去连接
- **THEN** 显示同步中断及最后观测，远端继续运行，重连后按序号补齐，不把断线认定为执行失败

### Requirement: 取消超时与恢复
取消 SHALL 区分排队与运行状态，运行任务经过取消中再确认终态。进程树使用平台适用机制，宽限 5 秒后可强制结束。自然结束后迟到取消不得改写终态。Agent 重启时不得自动重放已启动或结果未知的任务；无法证明进程退出时标为 recovery_required。

#### Scenario: 父子进程取消
- **WHEN** 用户取消正常前台父子进程任务
- **THEN** 目标确认进程收束后标记 cancelled，超时终止单独标记 timed_out

### Requirement: 受限结果文件
结果收集 SHALL 仅使用创建任务时指定的工作目录内子目录，拒绝路径穿越、符号链接和特殊文件。每任务最多 100 文件、单文件 500 MiB、总计 1 GiB；复制到专用结果区后生成 SHA-256 manifest，通过有所有权校验的 artifact ID 下载。收集状态与任务退出状态独立。

#### Scenario: 非法路径或大结果
- **WHEN** 结果包含逃逸路径或超出限制
- **THEN** 不读取范围外文件，标记收集不完整而不篡改真实执行结果
